# Prompt Template: Description → HTML Design

Use this template when gathering user inputs before generating HTML:

```
Design goal:
- [What should this visual communicate?]

Target platform and size:
- [e.g., Open Graph 1200x630, Story 1080x1920]

Style direction:
- [e.g., premium dark, playful gradient, minimalist editorial]

Content:
- Headline:
- Supporting text:
- CTA:
- Footer or badges:

Brand constraints:
- Primary colors:
- Forbidden colors:
- Logo usage:
- Language:

Technical constraints:
- Single-file HTML: yes/no
- External assets allowed: yes/no
- Need transparent background: yes/no
```

Then generate:
1. A self-contained HTML file.
2. A brief rationale for layout and color choices.
3. A screenshot export command.
